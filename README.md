# Bryan Projetos e Jogos

Site pessoal de portfólio, feito com HTML, CSS e JavaScript sem dependências. O Bairro Livre pode ser jogado no navegador pela pasta `bairro-livre/`, e Fuga da Ilha abre a experiência no Roblox.

## Abrir no computador

Abra `index.html` no navegador ou use **Open with Live Server** no VS Code, se tiver essa extensão.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub ou abra o repositório que publica o site.
2. Envie os arquivos desta pasta para a raiz do repositório, incluindo `index.html`, as pastas `assets/` e `bairro-livre/` completas.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique **Save**.
6. Aguarde o GitHub publicar o endereço mostrado na página de configurações.

O projeto pode continuar local nesta pasta mesmo depois de enviado ao GitHub. Não coloque senhas nem chaves privadas no site.

## Jogar o Bairro Livre

Abra `bairro-livre/index.html` ou acesse `/bairro-livre/` no site publicado. Os controles e o progresso salvo no navegador ficam descritos e exibidos na página do jogo.

## Jogar Fuga da Ilha

Na página inicial, selecione **Jogar Fuga da Ilha no Roblox** para abrir a experiência publicada no Roblox. As capas do portfólio ficam em `assets/`; mantenha essa pasta ao publicar para que as imagens dos projetos apareçam.
