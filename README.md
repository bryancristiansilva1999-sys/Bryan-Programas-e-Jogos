# Bryan Projetos e Jogos

Site pessoal de portfólio, feito em um único arquivo HTML com CSS e JavaScript embutidos. Não precisa instalar programas nem pacotes para visualizar.

## Abrir no computador

Abra `index.html` no navegador ou use **Open with Live Server** no VS Code, se tiver essa extensão.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub, por exemplo `bryan-projetos-jogos`.
2. Envie `index.html` para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique **Save**.
6. Aguarde o GitHub publicar o endereço mostrado na página de configurações.

O projeto pode continuar local nesta pasta mesmo depois de enviado ao GitHub. Não coloque senhas nem chaves privadas no site.
